🧪 Exercício – Testes de API com Postman
📌 Visão Geral

Este repositório contém um exercício prático de Testes de API, desenvolvido com o objetivo de validar funcionalidades, regras de negócio e respostas de uma API REST, utilizando o Postman como principal ferramenta.

O projeto foi criado para demonstrar meu conhecimento técnico em Quality Assurance (QA), incluindo testes funcionais de API, validações de respostas e organização de cenários.

🎯 Objetivo do Projeto

Validar endpoints de API REST

Testar fluxos positivos e negativos

Garantir que a API responda corretamente às requisições

Demonstrar boas práticas em testes de API

Evidenciar domínio da ferramenta Postman

🚀 Como Executar o Projeto
🔹 Pré-Requisitos

✔️ Postman instalado

👉 Download: https://www.postman.com/downloads/

🔹 Importar o Projeto no Postman

Abra o Postman

Clique em Import

Selecione os arquivos do repositório:

Collection (.json)

Environment (.json), se houver

Confirme a importação

🔹 Executar os Testes
✔️ Execução Manual

Abra a Collection

Execute as requisições individualmente

✔️ Execução Automatizada (Collection Runner)

Clique nos três pontos da Collection

Selecione Run collection

Inicie a execução

Os scripts de teste validam automaticamente as respostas da API.
